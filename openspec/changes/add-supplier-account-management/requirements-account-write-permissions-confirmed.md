# 供应商账号分级配置：已确认需求参考

状态：用户确认，实施参考（2026-09-24）。原讨论草案保留在 `requirements-account-write-permissions-draft.md`，以此文档为准。

## 目标

沿用管理员配置的 `review_required`。需审核时，供应商仅提交账号名称、账号类型及连接/登录必需的 Key、Token、邮箱、密码及类型专有字段，由管理员在审核界面补齐适用的账号配置、人工测试、再决定是否通过。免审时，供应商能配置适用于该账号类型的账号管理参数，使提交的账号直接可用。JWT、系统令牌、单个/批量创建和更新采用相同后端权限判定；前端根据当前权限只提供可用字段，不能只靠隐藏输入框授权。

## 确认的四项规则

1. **库存代理**：供应商默认必须选择已启用、未过期的库存代理。仅当平台没有可选代理时，才能选择“默认无代理”；如果存在可用代理则不能不选。OAuth 授权和账号提交都应遵循此规则；无代理不等于允许自定义代理地址或认证信息。
2. **复杂凭据**：连接必需的类型专有字段允许供应商配置，包括按类型必填的 `base_url`、AWS 区域/认证模式、Service Account JSON/区域、国内平台账户模式/协议等；非必需运行或调度字段在需审核模式禁止。不得将连接必需的 Token、Key 或密码当作可由管理员凭空补齐的配置。
3. **免审核分组/倍率**：管理员可为每个平台授权多个分组，旧单值配置迁移为单元素数组；后台按平台折叠显示分组、组内滚动多选。允许先保存未配置分组的免审设置，但对应平台的供应商账号提交必须拒绝，不能自动审核或投入客户流量。供应商不可配置计费倍率，一律按账号默认倍率 `1`。需审核时不可选分组；免审核时可多选管理员为该供应商提供且与平台/类型匹配的分组，未选择时可使用管理员预设的该平台首个分组；不能选择平台其他分组或直接写审核/调度状态。清空允许提交的账号类型时，供应商界面须正常显示空权限状态，管理员仍可编辑。
4. **测试**：不设强制测试成功门槛。需审核账号由管理员人工测试并判断是否批准；免审账号供应商可以自行测试，测试本身不改变审核状态，也不强制阻断创建。

## API/页面行为

- `/api/v1/supplier/me` 提供当前权限与免审时可选的授权分组。系统令牌页面现有接口教程根据当前权限生成可调用的创建、批量创建、更新请求体，**不向供应商解释审核信任等级或两套权限策略**。
- `POST /supplier/accounts`、`POST /supplier/accounts/batch`、`PUT /supplier/accounts/:id`：需审核时只接受 `name`、`platform`/`type`（创建）、可选 `external_id`、库存 `proxy_id`（无库存时可省略）、该类型必需的 `credentials`（包含长期保持连接所需的刷新凭据）与可选主动停用；禁止备注、并发、优先级、负载因子、过期时间、映射、计费倍率、分组、自定义 `extra` 等。超权字段和凭据子字段返回明确 422，不静默丢弃。
- 免审核时允许提交相关账号级设置：基本资料、有效库存代理、并发/优先级/负载因子、过期/停调、适用的模型及协议配置、经过逐项验证的高级配置；`group_ids` 必须来自该供应商获准的同平台分组。`rate_multiplier` 固定为 `1`，请求体不接收该字段。
- 免审账号修改非敏感模型映射/协议规则时，可仅提交这些 `credentials` 子字段，服务端合并保留原始隐藏凭据；修改连接凭据仍需提交完整的该类型连接字段。`extra` 更新保留非供应商可编辑的已有平台管理项。
- 保持账号归属隔离、账号类型白名单、上游 URL/SSRF 校验、凭据加密和脱敏、现有幂等语义。策略改变只影响之后的写入，不追溯改变历史审核状态；需审核时更新凭据或代理重新进入 `pending + disabled + schedulable=false`。
- 供应商可主动停用账号；需审核供应商不得自行恢复管理员暂停的账号，免审供应商可恢复已批准账号，不得启用待审核账号。
- 管理员审核编辑需补齐账号管理界面适用的配置项，不回填或可写供应商原始 Key/Token；保存配置不会自动批准，测试也不会自动批准。审批时仍要求有效代理（仅无库存例外）、有效分组，并明确提示通过后进入客户流量。
- 如果平台库存代理从“无”变“有”或变为过期，新写入必须按最新库存规则校验；对历史账号的处理不能静默清除归属或审核记录。

## 验收

1. 需审核的网页/令牌/批量提交仅接收最小连接字段且安全待审，伪造 `extra`、`group_ids`、`rate_multiplier` 等无效；管理员补齐配置、人工测试、审核通过才可服务客户。
2. 无库存代理时允许显式无代理，库存有有效代理时必须选择；禁用/过期代理不可提交。
3. 免审账号可按授权分组提交并使用相应账号参数，倍率仍为 `1`；无合法授权分组则拒绝自动通过。
4. 不同类型凭据必填与 URL 限制均生效；超权或跨供应商请求拒绝；敏感凭据不在列表、教程、审计中回显。
5. 系统令牌页面展示与后端同一权限的请求样例，权限切换后刷新可反映当前可提交字段。
